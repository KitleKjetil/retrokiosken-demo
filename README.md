# Retrokiosken – demoside

Statisk demo av designet til Retrokiosken, en planlagt norsk nettbutikk for originale retrospill (Game Boy, GBA, DS og Pokémon).

**Dette er ikke en ekte butikk.** Varer, priser og handlekurv er oppdiktet. Den ekte butikken bygges i Shopify.

- `index.html` – forside
- `spill.html` – alle varer med filter (`?k=gb|gba|ds|pokemon|konsoll|tilbehor`) og sortering
- `produkt.html?id=…` – produktside
- `assets/app.js` – demovarer, produktillustrasjoner (SVG), handlekurv
- `assets/style.css` – samme farger og font som Shopify-temaet

Produktbildene er egne pikselillustrasjoner – ingen offisielle bilder brukes.
Nintendo, Game Boy og Pokémon er varemerker som tilhører sine eiere.
